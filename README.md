# The-Next-Interview
 (הראיון הבא)
Every job starts with one project. The interview is where you prove it.
על המשחק
"הראיון הבא" הוא משחק מחשב על חיפוש עבודה. השחקן מסתובב בעיר קטנה, פוגש אנשים ובונה איתם קשרים, ופותר חידות מתמטיות בחדר החידות. כל חידה שנפתרת מוסיפה פרויקט, והפרויקטים והקשרים פותחים משרות עם שכר גבוה יותר. בחדר המשרות השחקן מתראיין למשרה מסוימת מול מראיין מבוסס בינה מלאכותית, שנותן ציון לכל תשובה. אם הציון הסופי עומד בדרישות של המשרה, השחקן מתקבל.
